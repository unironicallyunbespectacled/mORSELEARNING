The 30-Day Curriculum
Koch + Farnsworth method

Real CW instructors don't teach the alphabet in ABC order at slow speed — that trains your eye to "decode a chart," which caps out around 5–8 WPM and has to be unlearned later. Instead this program uses two techniques used by working amateur radio operators:

1 · Koch Method

Start with just 2 characters played at full target speed (20 WPM), and add one new character only once you can copy the current set accurately. Your ear learns each letter's true rhythm-shape from day one — never a slowed-down, distorted version you'll have to relearn.

2 · Farnsworth Spacing

Characters play fast, but the gaps between them are stretched out (an "effective WPM" lower than the character speed). This gives your brain time to recognize each shape without slowing the shape itself down. As you improve, you shrink the gaps — not re-teach the shapes.

3 · Pattern Logic

Don't rote-memorize 40 codes. Digits follow a strict dot/dash ramp (see Reference), many letters are exact rhythmic mirrors of each other, and letters group cleanly by element-count. Learn the structure once and half the alphabet becomes obvious.

Number Pattern Logic
no memorization needed

Digits 1–5

1=.---- 2=..--- 3=...-- 4=....- 5=.....
Number of dots = the digit. Fill the rest of 5 total elements with dashes.

Digits 6–0

6=-.... 7=--... 8=---.. 9=----. 0=-----
Number of dashes = digit − 5 (0 counts as 10). Fill the rest with dots — the exact mirror of 1–5.

Why this matters

Once you see the ramp, all ten digits become one rule instead of ten codes to memorize. Test yourself: what's the code for 7? (two dashes, three dots — you just derived it.)
